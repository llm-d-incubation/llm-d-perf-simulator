BLIS blackbox inference simulator an incubating component of llm-d

Know how a serving configuration performs before you book the accelerators.

BLIS prices one forward pass from a model graph, a chip and calibrated coefficients, then sweeps that over configurations: tensor parallelism, instance counts, batch limits. It predicts fleet throughput, per-user token rate and tail latency for a given model, accelerator budget and workload.

Where this fits

BLIS is an incubating component of llm-d, the Kubernetes-native stack for distributed LLM inference. llm-d deploys and scales serving engines across a cluster; BLIS answers the question that comes first, which is what to deploy. The engine and routing flags a search returns, things like max-num-seqs, max-num-batched-tokens and tensor-parallel width, are the knobs you then set on a real deployment.
